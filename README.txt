# Тыва Мессенджер — веб-прототип

Откройте `index.html` в браузере. Это демонстрационный интерфейс:
- фирменный геометрический фиолетовый логотип;
- светлая и тёмная темы;
- боковое меню;
- список чатов, поиск и демонстрационная переписка;
- адаптация для телефона.

Важно: это пока локальный прототип. Сообщения не отправляются другим людям, нет регистрации, сервера, базы данных и звонков.
